# 課題集

各章を読んだ後に取り組む課題

全部を一気にやる必要はない。1つ実装したら起動して確認する、小さいサイクルで進める

## 課題の選び方

完全初心者は手順付き課題01から順番に進める

フロントエンド経験者は、手順付き課題01を確認にとどめ、課題03、課題04、課題06を重点的に進める

PHP/Laravel経験者は、課題03をController追加、課題04をバリデーション、課題06をJSONレスポンスとして見ると理解しやすい

| 課題 | 完全初心者 | フロントエンド経験者 | PHP/Laravel経験者 |
| --- | --- | --- | --- |
| 課題01 | 必須 | 確認だけでも可 | 確認だけでも可 |
| 課題02 | 必須 | 必須 | 必須 |
| 課題03 | 必須 | 必須 | 必須 |
| 課題04 | 必須 | 必須 | 必須 |
| 課題05 | 必須 | 確認だけでも可 | 確認だけでも可 |
| 課題06 | 発展 | 推奨 | 推奨 |
| 課題07 | 必須 | 必須 | 必須 |
