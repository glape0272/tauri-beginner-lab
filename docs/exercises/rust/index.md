# Rust基本から中級課題

手順を写す学習ではなく、自分で考えてRust側の処理を組み立てるための課題集

Tauri commandとしてTypeScriptから呼び出せる形を前提にしつつ、Rust単体の考え方も確認する

## 進め方

- 先に要件を読み、実装方針を短くメモする
- すぐに答えを探さず、型と戻り値を先に決める
- 1課題ごとに小さく動作確認する
- エラー文はユーザーに見せる文章として書く
