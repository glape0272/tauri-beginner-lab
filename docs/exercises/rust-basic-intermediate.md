# Rust基本から中級課題

この課題集は、手順を写す学習ではなく、自分で考えてRust側の処理を組み立てるための課題です。

Tauri commandとしてTypeScriptから呼び出せる形を前提にしつつ、Rust単体の考え方も確認します。

## 進め方

- 先に要件を読み、実装方針を短くメモする
- すぐに答えを探さず、型と戻り値を先に決める
- 1課題ごとに小さく動作確認する
- エラー文はユーザーに見せる文章として書く

## 基本課題

### Rust-01: 文字列を整形する

対象ファイル:

- `src-tauri/src/lib.rs`

要件:

- 名前と学習テーマを受け取るTauri commandを作成
- 戻り値は1つの文章
- 空文字の場合は`Err`を返す

制約:

- 戻り値は`Result<String, String>`
- TypeScript側の引数名とRust側の引数名を一致させる

完了条件:

- 正常入力で文章が返る
- 空文字でエラーが返る

### Rust-02: 数値を判定する

対象ファイル:

- `src-tauri/src/lib.rs`

要件:

- 点数を受け取り、評価文を返すTauri commandを作成
- 80以上は`Excellent`
- 60以上は`Good`
- 60未満は`Retry`

制約:

- 点数が100を超える場合は`Err`
- 点数型は整数型

完了条件:

- 境界値の`59`、`60`、`80`、`101`で結果を説明できる

### Rust-03: 配列を集計する

対象ファイル:

- `src-tauri/src/lib.rs`

要件:

- 複数の学習時間を受け取り、合計時間を返す
- 空配列の場合は`Err`
- 1日の学習時間が8時間を超える値がある場合は`Err`

制約:

- 引数は`Vec<u8>`
- 戻り値は`Result<u16, String>`

完了条件:

- 正常な配列で合計が返る
- 空配列と異常値でエラーが返る

## 中級課題

### Rust-04: structを返す

対象ファイル:

- `src-tauri/src/lib.rs`

要件:

- 学習ステータスを表す`struct`を作成
- タイトル、進捗率、次にやることを返す
- TypeScript側で扱いやすいフィールド名にする

制約:

- `serde::Serialize`を付ける
- commandの戻り値は作成した`struct`

完了条件:

- TypeScript側で型定義できる形のJSONとして返る

### Rust-05: Optionを使って任意入力を扱う

対象ファイル:

- `src-tauri/src/lib.rs`

要件:

- メモ本文と任意のタグを受け取る
- タグがない場合は`"未分類"`として返す
- 本文が空の場合は`Err`

制約:

- タグは`Option<String>`
- 戻り値は`Result<String, String>`

完了条件:

- タグあり、タグなし、本文空の3パターンを説明できる

### Rust-06: Vec<struct>を返す

対象ファイル:

- `src-tauri/src/lib.rs`

要件:

- 学習ログの一覧をRust側で作成して返す
- 各ログはid、タイトル、本文、作成日を持つ
- 2件以上返す

制約:

- `Vec<LearningNote>`を返す
- TypeScript側で配列として受け取れるフィールド名にする

完了条件:

- Rustで作成した複数ログをTypeScript側で一覧表示できる

## 仕上げ課題

### Rust-07: 入力検証をまとめる

対象ファイル:

- `src-tauri/src/lib.rs`

要件:

- 学習ログ追加用のcommandを設計
- タイトル、本文、学習時間を受け取る
- 入力検証を行い、成功時は作成したログ情報を返す

制約:

- タイトルと本文は空文字不可
- 学習時間は1以上480以下
- 戻り値は`Result<struct, String>`

完了条件:

- どの入力で成功し、どの入力で失敗するか説明できる
